# Khojo AI changelog

The first "## x.y.z" heading is the app version. The "###" sections and "-" bullets below it become the update notes shown on the phone.
Phase = minor, mini-sprint = patch (e.g. Phase 1 Sprint 4 Mini-C = 0.1.5).

## 0.1.1 - 2026-11-10

### Added
- Consent screen after the intro: cloud AI is off unless you allow it.
- "Add photos" button: pick photos with the system picker and see how many were added.

## 0.1.0 - 2026-11-10

### Added
- Intro slides on first launch (3 screens, Skip works), in English and Hindi.
- Dark mode and a splash screen.

## 0.0.5 - 2026-11-10

### Changed
- Update test build: if you can read this on your phone, the in-app update works.

## 0.0.4 - 2026-12-08

### Changed
- One app for everyone: it keeps itself up to date from our servers (no Play Store).

## 0.0.3 - 2026-12-07

### Added
- Beta builds now tell you when a newer version is available and can download and install it.

## 0.0.2 - 2026-11-30
